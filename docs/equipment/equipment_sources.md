# Откуда берутся цены оборудования

Утверждено 08.11.2026. **Все цены на панели, инверторы, крепёж, кабель и защиту в веб-сервисе берутся только с сайтов из этого списка.** Других источников цен для каталога нет. Новый сайт можно добавить, только если он прошёл ту же проверку (ниже).

## Правила

1. **Только проверенные сайты** из таблицы ниже.
2. **Обычная цена, без скидок.** Если на сайте цена зачёркнута и рядом стоит цена со скидкой, в каталог идёт зачёркнутая — цена до скидки. Акции, скидки «для юрлиц», скидки зарегистрированным покупателям не учитываются.
3. **Несколько продавцов — медиана.** У модели берётся по одной обычной цене от каждого продавца, в каталог идёт медиана. Разброс показан в колонке `price_note` каталога.
4. **Только модели с паспортом.** Модель попадает в расчёт, только если в репозитории есть паспорт производителя: без напряжений, токов и температурных коэффициентов конфигуратор не может её посчитать. Цены моделей без паспорта всё равно записываются, с пометкой `used = no`. Они нужны для задачи T2.9.
5. **Дата у каждой цены.** Цены обновляются вручную: Р2 раз в месяц открывает страницы из `offers.csv` и правит цены.

Где лежит:
- `data/equipment/offers.csv` — все записанные предложения: продавец, ссылка, обычная цена, цена со скидкой, наличие, дата, берётся ли в расчёт и почему.
- `python scripts/build_equipment_prices.py` пересчитывает из них цены в `panels.csv`, `inverters.csv` и `bos.csv`.

## Как проверялись сайты (08.11.2026)

Сайт должен:
- открываться;
- показывать цены в рублях на карточках товаров;
- иметь реквизиты юрлица или ИП (ИНН или ОГРН) и адрес.

Реквизиты взяты с самих сайтов, с ЕГРЮЛ мы их не сверяли. Это можно сделать на egrul.nalog.ru.
