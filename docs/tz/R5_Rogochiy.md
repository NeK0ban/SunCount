**Роль:** качество (автотесты, воспроизводимость), отчёты, презентации, материалы для гранта.

## 1. Зачем эта роль

По ТЗ курса проект принимают, если «калькулятор работает на всех портретах и тарифах, **расчёты воспроизводимы**, а обе гипотезы проверены с опорой на данные». Воспроизводимость — твоя зона. Критерий звучит так: «Расчёт воспроизводится по инструкции на другом компьютере». Ещё на тебе вся сдаваемая отчётность из ТЗ:
- промежуточный доклад 5–7 минут;
- итоговый отчёт (вопрос, гипотезы, исходные данные, методика, результаты, выводы, ограничения и допущения);
- итоговая презентация 7–10 минут;
- паспорт проекта;
- материалы для заявки на грант.

### T5.2. Проверка воспроизводимости (06.12 и 18.12)

**Зачем:** прямой критерий приёмки ТЗ.

**Шаги (оба раза):**
1. На **своём** компьютере, в новой папке (не в рабочей копии):
   ```bash
   git clone https://github.com/NeK0ban/SunCount.git SunCount_check
   cd SunCount_check
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Выполнить по порядку команды из раздела 8 мастер-ТЗ (или из README), затем `python -m pytest -q` и `streamlit run app/streamlit_app.py`.
3. На каждом шаге записать результат в `docs/reproducibility_check.md`:

```markdown
# Проверка воспроизводимости — <дата>, № <1 или 2>
- Компьютер / ОС:
- Версия Python (`python --version`):
- Коммит (`git rev-parse --short HEAD`):

| Шаг | Команда | Результат (ок / ошибка) | Текст ошибки | Как исправлено |
|---|---|---|---|---|
```

4. Каждую ошибку — исправить через PR (README, `requirements.txt`) или передать автору скрипта.

**Известная проблема для исправления:** `scripts/make_interim_report.py` (регистрация шрифтов `C:/Windows/Fonts/arial*.ttf` для PDF) и графики (`font.family = "Arial"` в `make_interim_report.py`, `estimate_capex.py`) не работают без Windows.
- **Решение:** если файла Arial нет, брать шрифт DejaVu Sans. Он ставится вместе с matplotlib, путь — `matplotlib.font_manager.findfont("DejaVu Sans")`. Для графиков — `font.family = ["Arial", "DejaVu Sans"]`.
- Правку скриптов согласовать с Р1: это его скрипты.

**Дополнительно:** закрепить версии в `requirements.txt` — заменить `>=` на `==` версиями из `pip freeze` рабочего окружения Р1.

*Готово, когда:* все шаги «ок» на чистом компьютере без ручных правок.
