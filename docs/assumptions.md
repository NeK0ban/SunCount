# SunCount — реестр параметров, допущений и учтённых факторов

Документ для раздела отчёта «Исходные данные, методика, допущения и ограничения».
Обновляется при каждом изменении модели. Код параметров — `src/econ/params.py`, входные данные — `src/econ/inputs.py`.

Статусы: **Офиц.** — официальный источник · **Факт** — опубликованные фактические данные · **Расчёт** — получено расчётом из открытых данных · **Допущение** — нет официального значения, обосновано и проверяется в чувствительности · **Условно** — временное значение до получения данных.

## 2. Факторы, учтённые в модели (сверх формулы ТЗ)

Формула ТЗ: *годовой эффект = самопотребление × тариф + излишки × цена выкупа*. Модель (`annual_effect_monthly`) уточняет её:

1. **Диапазоны тарифа по объёму потребления.** Эффект считается как разница счетов «без СЭС» и «с СЭС» по каждому месяцу; объём сверх 1100 (1700) кВт·ч/мес оплачивается по ставке II (III) диапазона. СЭС «срезает» самые дорогие кВт·ч. Пример: дом 18 000 кВт·ч/год, 10 кВт — эффект на **+18 %** выше формулы ТЗ.
2. **Цена выкупа зависит от тарифа владельца.** Одноставочный — 1-я ценовая категория (≈ 4,44 ₽), день/ночь — дневная зона 2-й категории (≈ 7,52 ₽).
3. **Сезонность цены выкупа и выработки.** Излишки каждого месяца умножаются на цену этого месяца; выработка по месяцам — PVGIS.
4. **Тариф «день/ночь».** Самопотребление замещает только дневную энергию (солнце светит в 7–23); ночной импорт оплачивается по ночной ставке.
5. **НДФЛ после окончания льготы** (с 2029 г.) — в денежных потоках дисконтированного расчёта.
6. **Индексация с 1 июля** — средняя за год цена учитывает полгода до и после индексации.
7. **Деградация панелей, замена инвертора, дисконтирование по меняющейся ключевой ставке.**

## 3. Ограничения (что модель НЕ учитывает)

- Вся выработка относится к дневной зоне (7–23): летом панели работают примерно с 5–6 утра, т. е. частично в ночной зоне. При помесячных данных модель считает, что самопотребление замещает только дневную энергию, — эффект тарифа день/ночь немного завышен. Точно — по почасовым данным команды 1.
- Трёхзонный тариф (пик/полупик/ночь) — данные есть в `data/tariffs_2026.csv`, в расчёт пока не включён.
- Аккумуляторы (гибридные СЭС) — вне рамок ТЗ, в плане развития.
- Деградация уменьшает самопотребление и излишки пропорционально (на самом деле в первую очередь уменьшаются излишки — оценка эффекта консервативна).
- Изменение правил выкупа и тарифов, не отражённое в прогнозе МЭР (например, отмена льготы для сельского населения).
- Капзатраты — оценка по ценам компонентов и комплектов, не персональные КП; плата за техприсоединение микрогенерации принята минимальной (не подтверждена текстом приказа ДГРТ № 19/2025-э).
