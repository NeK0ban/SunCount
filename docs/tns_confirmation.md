## Найдено попутно: помесячный зачёт (ОП № 442, п. 63(1))

Для гражданина на одноставочном тарифе объём продажи — «определенная по итогам расчетного периода величина, на которую объем выданной в сеть электрической энергии превышает объем принятой из сети», а объём покупки — наоборот. На тарифе по зонам суток — то же по каждой зоне. Это противоречит глоссарию мастер-ТЗ («Сальдирование … для физлиц не применяется»). Мастер-ТЗ не меняем; решение записано в `PLAN.md` (блок «Решения команды», 21.10.2026), в модели — вариант `annual_effect_monthly_net()`.
