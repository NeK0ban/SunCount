# SunCount — проверенный энергетический пакет команды №1

**Версия:** 02.11.2026, многолетняя солнечная база PVGIS-SARAH3 (2005–2023).

**Статус:** расчётная солнечная база и энергетические CSV **готовы**. Потребление — сценарные, не измеренные реальные семьи; оригинальный интерфейс `MonthlyMetrics` команды 2 ещё не получен. См. `reports/RESULTS_REPORT.md`.

## Главное

- 2 предоставленных пользователем PVGIS JSON по **166 536 часов**, каждый; внутренние параметры и полнота проверены. Исходный пользовательский архив — `data/pvgis_raw/pvgis_2005_2023_original_upload.zip`.
- Краснодар 1223.55 кВт·ч/(кВт·год), Майкоп 1210.43; многолетнее среднее для наклона 30°, юга и потерь 14%.
- `results/energy_metrics.csv` — 24 годовых сценария (4 × 2 × 3).
- `results/energy_metrics_monthly.csv` — 288 помесячных сценариев.
- `results/hypothesis_equal_consumption.csv` — сравнение двух портретов при 3500 кВт·ч/год.
- `results/solar_monthly_2005_2023.csv` — сезонность 1/3/5/10 кВт и `solar_yearly_2005_2023.csv` — разброс по годам.
- `results/comparison_team2_reference.csv` — **существенное несоответствие** референтным месяцам команды 2 (нужна сверка).
- `src/energy/api.py` — функции `build_profile`/`simulate`, 8760 точек и 12 `MonthlyMetrics`.
- `data/hourly_profiles/` — 8 файлов по 8760 значений; `data/hourly_solar/` — 6 файлов по 8760 значений.
- `reports/charts/` — зимний/летний день, сопоставление мощностей и график гипотезы.

## Установка и воспроизведение (без интернета)

Из корня архива:

```bash
python -m pip install -r requirements.txt
python -m scripts.import_uploaded_pvgis
python -m scripts.generate_outputs --mode verified
python -m unittest discover -s tests -v
```

Проверка оригинального архива проверяет: координаты, базу SARAH3/ERA5, 2005–2023, 30°, юг, 14%, 1 кВт, непрерывность 166 536 часовых меток, отсутствие отрицательных мощностей; сохраняются SHA256 и многолетние средние. Время источника UTC переводится в UTC+3, 29 февраля исключено, данные группируются по конкретному месяцу, дню и часу. `2023` в датах CSV — **только календарь типового невисокосного года**.

**Внимание:** не запускайте `--mode demo` при сдаче результатов: эта команда перезапишет PVGIS-кэш условными данными. Для восстановления выполните команду `python -m scripts.import_uploaded_pvgis` и затем `--mode verified`.

`src/econ/exchange.py` — восстановленный локальный класс (поля прежнего v1.0), требует сверки с оригиналом команды №2 перед слиянием кода. `self_night_kwh` в v1.0 не добавлен. Наблюдения реальных семей отсутствуют.
