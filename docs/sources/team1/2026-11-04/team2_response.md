2. **Изменение почасового потребления между прежним пакетом и 02.11.** При реализации `build_profile` прежнюю модель отдельных включений приборов заменили плавной суммой фоновой нагрузки, утреннего и вечернего пиков с нормированием к прежней сумме каждого месяца; границы тарифных зон не меняли. Из-за более высокого ночного фона и хвоста вечернего пика в 23:00 для января `day_absent`, Краснодар, 3 кВт ночная покупка выросла с 36,815039 до 66,878379 кВт·ч (доля ночной нагрузки с 13,306% до 24,172%); это изменение сценарной модели, без калибровки по измерениям.
