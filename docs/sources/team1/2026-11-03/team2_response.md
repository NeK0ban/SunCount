# SunCount — ответ команды №1 команде №2

**Дата:** 03.11.2026  
**Тема:** исправлен расчёт самопотребления — отдельно по 19 годам PVGIS

Коллеги, замечание принято, алгоритм исправлен. Раньше показатели рассчитывались по среднему почасовому году, теперь мы для **каждого года 2005–2023 отдельно** выполняем почасовые `self=min(load,gen)`, импорт и экспорт, разбиваем импорт по тарифным периодам, суммируем за каждый месяц и только после этого усредняем 19 годовых месячных результатов. Доли `self_share` и `coverage` вычисляются из средних энергий, а не как среднее процентов.

**Время и параметры:** UTC+3; 29 февраля удалён, ночные 00:00–02:59 1 января 2005 года заполняются нулём. PVGIS-SARAH3 + ERA5, наклон 30°, юг, потери 14%, горизонт, мощности 3/5/10 кВт. Модель нагрузки фиксирована на 8760 часов во всех годах для сопоставимости.

**Итог исправления:** старый расчёт завышал долю самопотребления на **0,72–6,36 п.п.** по 24 сочетаниям, в соответствии с диапазоном вашей проверки. Детальная сверка: `results/team1_typical_year_check.csv`. Отдельные годовые значения: `results/energy_metrics_per_year.csv` (456 строк), по месяцам: `results/energy_metrics_monthly_per_year.csv` (5472 строки).

**Исправлены основные файлы v1.0:** `results/energy_metrics.csv` (24 строки), `results/energy_metrics_monthly.csv` (288 строк). Колонки и порядок совместимы с прежним пакетом, `self_night_kwh` не добавляли.
