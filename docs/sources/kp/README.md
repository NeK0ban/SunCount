# Оригиналы ответов на запросы КП

Сюда кладём оригиналы ответов установщиков: PDF, скриншоты, вложения писем. Цифры из них заносятся в `data/kp_responses.csv` (задача T2.4, мастер-ТЗ раздел 12.2).

Имя файла: `YYYY-MM-DD_<компания>_<что>.<расширение>`, например `2026-10-20_ekoproekt_komplekt_3kw.png`.

Личные контакты сотрудников компаний (имена, мобильные телефоны) в репозиторий не выкладываем: при необходимости закрасить на скриншоте.
