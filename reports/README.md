# Что лежит в reports/

Правило: в корне папки — только главные результаты проекта по ТЗ (промежуточный и итоговый отчёт, доклады). Всё остальное — по подпапкам.

## Корень — результаты проекта по ТЗ

| Файл | Что это | Кто делает |
|---|---|---|
| `SunCount_interim_report.pdf` | Промежуточный отчёт; собирается скриптом `python scripts/make_interim_report.py` | Р1 |
| `SunCount_interim_talk.pptx` | Промежуточный доклад и прожарка (14 слайдов, шаблон АГУ, текст докладчиков — в заметках); собирается скриптом `python scripts/make_interim_talk.py`, скриншот веб-сервиса — `interim_talk/web_service.png`; текст выступления по слайдам — `interim_talk/tekst_doklada.md` (собирается тем же скриптом), вопросы экспертов с ответами — `interim_talk/voprosy_i_otvety.md` | Р5 (черновик — Р1) |
| `SunCount_final_report.docx` *(будет)* | Итоговый отчёт | Р5 |
| `SunCount_final_talk.pptx` *(будет)* | Итоговая презентация | Р5 |

## ip_truba/ — Экспертная труба по интеллектуальной собственности (18.11.2026)

- `SunCount_IS_truba.pptx` — презентация на три слайда по рекомендациям организаторов; собирается `python scripts/make_ip_talk.py`.
- `tekst_vystupleniya.md` — текст на 3 минуты (собирается тем же скриптом).
- `pamyatka_komande.md` — памятка команды: ответы по четырём критериям экспертов, слабые места, чек-лист до 18.11, вопросы и ответы.
- `soglashenie_o_pravah_chernovik.md` — черновик соглашения участников о правах на результаты.

## kurs/ — задания курса по лекциям (по порядку)

| Папка | Задание | Файлы |
|---|---|---|
| `01_tema_zadel_gipoteza/` | Тема, задел и гипотеза проекта | презентация |
| `02_problema_potrebitelya/` | Аналитическая записка «Проблема потребителя и держатель проблемы» | записка (Word) + презентация |
| `03_opisanie_produkta/` | Аналитическая записка «Описание проектного продукта. Техническое описание» | записка (Word) + слайд «Решение» |
| `04_konkurenty/` | Аналитическая записка «Конкурентные преимущества, оценка рынка: разведывательный анализ» | записка (Word) + презентация |

Новое задание — новая папка со следующим номером: `04_…`.

## pasport/ — паспорт проекта

`SunCount_pasport_proekta.xlsx` — вопрос, тема, цели, ссылки, команда и роли.

## scheme/ — схема решения

`SunCount_scheme.pptx` и `SunCount_scheme.png` — схема решения (мастер-ТЗ 5.0, переделана 08.11.2026 фигурами PowerPoint: её можно править и вставлять в презентации; та же схема — на слайде доклада): что сообщает пользователь, что знает сервис, подбор, что получает пользователь. Собирает `python scripts/make_scheme.py`.

## weekly/ — недельные отчёты

`SunCount_nedelya_<неделя>.docx` (до 08.11) и `nedela<ДДММ>.docx` (с 09.11, ДДММ — понедельник недели, например `nedela0911.docx`) — готовые отчёты; текст правится в `weekly/src/<то же имя>.md`, docx собирает `python scripts/make_weekly_report.py`.
