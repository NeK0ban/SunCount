# Что лежит в reports/

Правило: в корне папки — только главные результаты проекта по ТЗ (промежуточный и итоговый отчёт, доклады). Всё остальное — по подпапкам.

## Корень — результаты проекта по ТЗ

| Файл | Что это | Кто делает |
|---|---|---|
| `SunCount_interim_report.pdf` | Промежуточный отчёт; собирается скриптом `python scripts/make_interim_report.py` | Р1 |
| `SunCount_interim_talk.pptx` *(будет)* | Промежуточный доклад, 15.11 | Р5 |
| `SunCount_final_report.docx` *(будет)* | Итоговый отчёт | Р5 |
| `SunCount_final_talk.pptx` *(будет)* | Итоговая презентация | Р5 |

## kurs/ — задания курса по лекциям (по порядку)

| Папка | Задание | Файлы |
|---|---|---|
| `01_tema_zadel_gipoteza/` | Тема, задел и гипотеза проекта | презентация |
| `02_problema_potrebitelya/` | Аналитическая записка «Проблема потребителя и держатель проблемы» | записка (Word) + презентация |
| `03_opisanie_produkta/` | Аналитическая записка «Описание проектного продукта. Техническое описание» | записка (Word) + слайд «Решение» |

Новое задание — новая папка со следующим номером: `04_…`.

## pasport/ — паспорт проекта

`SunCount_pasport_proekta.xlsx` — вопрос, тема, цели, ссылки, команда и роли.

## weekly/ — недельные отчёты

`SunCount_nedelya_<неделя>.docx` — готовые отчёты; текст правится в `weekly/src/<неделя>.md`, docx собирает `python scripts/make_weekly_report.py`.
