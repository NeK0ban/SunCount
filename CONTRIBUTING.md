# Как отправлять свою работу в SunCount

Напрямую в этот репозиторий пушить нельзя: у участников доступ только на чтение. Работа идёт через форк (свою копию репозитория) и pull request. Руководитель смотрит изменения и либо принимает их в `main`, либо возвращает на доработку с комментариями.

## Первый раз: форк и клонирование

1. Откройте https://github.com/NeK0ban/SunCount и нажмите **Fork** (справа вверху), затем **Create fork**. У вас появится копия `github.com/<ваш-логин>/SunCount`.
2. Склонируйте свою копию и подключите оригинал как `upstream`, чтобы потом подтягивать свежие изменения:

```
git clone https://github.com/<ваш-логин>/SunCount.git
cd SunCount
git remote add upstream https://github.com/NeK0ban/SunCount.git
```

## Каждая новая задача

1. Обновите свой `main` до актуального состояния оригинала:

```
git checkout main
git pull upstream main
git push origin main
```

2. Создайте ветку под задачу. Называйте её по смыслу, например `team1-generation-data` или `fix-tariff-2026`:

```
git checkout -b team1-generation-data
```

3. Работайте, коммитьте как обычно, затем отправьте ветку в свой форк:

```
git add .
git commit -m "Коротко, что сделано"
git push -u origin team1-generation-data
```

4. Откройте свой форк на GitHub. Появится жёлтая плашка **Compare & pull request**, нажмите её. Проверьте, что сверху указано `NeK0ban/SunCount : main ← <ваш-логин>/SunCount : ваша-ветка`, напишите в описании, что сделано и что проверить, и нажмите **Create pull request**.

## Если попросили доработать

Исправьте всё в той же ветке и снова сделайте `git push`. Новые коммиты сами добавятся в открытый pull request, создавать новый не нужно.

## Правила

- Одна задача — одна ветка — один pull request. Не смешивайте в одном PR данные, код и отчёт по разным задачам.
- Не коммитьте личные данные, пароли и файлы больше нескольких мегабайт без согласования.
- Данные меняйте в CSV, а не в `SunCount_data.xlsx` (он собирается скриптом, см. README).
- После того как PR принят, ветку можно удалить: на GitHub появится кнопка **Delete branch**.
